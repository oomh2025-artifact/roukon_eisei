労働衛生ドリル（PWA版）の置き方

このフォルダの中身（index.html、manifest.webmanifest、sw.js、icon-*.png）を、
https:// で配信できる場所に、フォルダごと置きます。ファイル名は変えません。

GitHub Pages を使う手順（無料。所要5〜10分）
1. https://github.com にログインし、右上の「+」→「New repository」を押します。
2. Repository name に好きな名前（例 eisei-drill）を入れ、Public を選び、「Create repository」を押します。
3. 「uploading an existing file」を押し、このフォルダの中の全ファイルをドラッグして入れ、「Commit changes」を押します。
4. リポジトリの「Settings」→左の「Pages」→「Branch」で main を選び「Save」を押します。
5. 1〜2分後に、同じ画面に https://（ユーザー名）.github.io/（リポジトリ名）/ が表示されます。
6. Android の Chrome でその住所を開き、右上のメニュー（⋮）→「ホーム画面に追加」（または「アプリをインストール」）を押します。

更新するとき
新しい index.html と sw.js を同じ場所に上書きします。アプリを開き直すと更新されます。

学習の記録
記録は端末の中に保存されます。別の端末へ移すときは、アプリの「設定」→「書き出す」の文字列を、移し先の「設定」に貼り付けて「読み込む」を押します。
